# Recipe Book

A simple web-based Recipe Book project for ITVarsity assessment. This site allows users to browse and view recipes for meals, drinks, and desserts.

## Features

- Browse recipes by category: Meals, Drinks, Desserts
- View ingredients and step-by-step instructions for each recipe
- Responsive design with styled pages
- Uses [Font Awesome](fontawesome.html) for icons

## Getting Started

1. **Clone the repository:**
   ```sh
   git clone https://github.com/Ty-xn-ITvarsity/Module-3-Assessment-1/recipe-book.git
   ```
2. **Open the project folder.**
3. **Open `index.html` in your web browser to start.**

## Project Structure

- `index.html` – Home page
- `meals.html`, `drinks.html`, `desserts.html` – Category pages
- Individual recipe pages (e.g., `cookies.html`, `lemonade.html`)
- `styles.css` – Main stylesheet
- `fontawesome/` – Font Awesome icons and CSS
- `images/` – Recipe and logo images

## Dependencies

- [Font Awesome](fontawesome.html) (included locally in `fontawesome/`)
